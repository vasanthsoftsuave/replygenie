# Apologetic

## Description
Sincere and humble — acknowledges a mistake, inconvenience, or problem and expresses genuine regret.

## Prompt
A sincere, humble tone that acknowledges the mistake, inconvenience, or problem and expresses genuine regret.

## Example Input
hey can you send me that file when you get a sec

## Example Output
I'm sorry for the back-and-forth — whenever you're able to, could you send that file over? I really appreciate it.
